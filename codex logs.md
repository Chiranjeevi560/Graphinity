# Codex project log

This file is a handoff for Claude and other contributors. It records the project state and work visible to Codex on 2026-10-22. Keep it current as implementation continues; distinguish verified implementation from plans.

## Owner direction

Graphinity is intended to become a consent-first personal intelligence and commercial platform. The owner wants to collect and use the maximum useful amount of voluntarily provided or Graphinity-generated first-party information **when the person has clearly opted in**. Every data category and purpose must be explained, independently controllable where feasible, inspectable, exportable, revocable, and deletable. Commercial relevance should favor user value over engagement. Partner sharing and enterprise products must obey category-specific authorization and privacy protections. No hidden collection, dark patterns, fingerprinting, or undisclosed tracking.

The pasted master prompts also require broad production hardening, a first-party personal knowledge graph, personalization, privacy-preserving commerce and enterprise intelligence, architecture records, operational documentation, and a root `project report.md`. They set a $0/month free-tier constraint. Some requirements in the prompts conflict (one mandates zero-PII/no personal data sale, while the later owner direction permits consented first-party personalization and partner programs). Resolve this by honoring the owner's latest direction while retaining explicit consent, transparency, revocation, and appropriate aggregation as hard constraints. Do not assume legal compliance merely because a user consented; jurisdiction-specific review remains necessary before launch.
